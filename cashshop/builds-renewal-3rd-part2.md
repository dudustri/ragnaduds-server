## How to read this

- **Classes/tiers in rAthena renewal:** AB/Sura/GX/SC/Mechanic/Genetic are checked as *transcendent 3rd* (Third_Upper) - "OK (trans+non-trans 3rd)" means both work. Star Emperor, Soul Reaper and Expanded Super Novice are *non-trans 3rd* (Third). **Kagerou/Oboro and Rebellion are "Normal" tier** in rAthena, so any item flagged `All_Third`/`Third` only (e.g. Temporal X Boots 22000-22011, Zodiac Boots, class Records) is unusable by them - replaced below.
- **Mid tier (Lv ~100-160):** built around the Glast Heim **Honor set** (bRO "Equipamentos de Honra"; bROWiki route Lv100-150): class skill suit + Attack/Magic Manteau + Boots + Ring = 4-piece combo. Listed as **Grace** (Lv150); swap to **Noblesse** (Lv100) / **Imperial** (Lv125) versions earlier - same names, same combo.
- **Endgame (Lv175-200):** class "Patent" (= "Awakened" in iRO text) / -LT / Adulter Fides weapons, Helm of Faith / Temporal Circlet / Biolab crowns, **Automatic** set (bROWiki "Automatron", Lv160+), Ring of Unknown Hero, class shadow sets.
- **Cards:** listed cards fit the item's slot count; "Card alt" in Notes are verified alternatives. Shadow gear has no slots.
- **Accessory R / L:** Ring of Unknown Hero, Document/Record (Right), Automatic Booster L, King Schmidt Insignia, Perverse Demon Mask, Gigantes Card (Left) are side-locked - kept on the correct side.
- Refine targets follow the guides (+9/+11 mid, +12-14 endgame where the guide says so).
